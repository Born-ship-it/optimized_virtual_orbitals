\chapter{Computational Details}
\label{ch:computational}

In this chapter, we provide a comprehensive account of the computational details underlying all calculations presented in this thesis. This includes the software and libraries used, the molecular geometries and basis sets employed, the settings for the reference SCF calculations, and the specific hyperparameters of the OVOS optimisation. The goal is to ensure that all results are fully reproducible by any reader with access to similar computational resources.


\subsection{Software and Libraries}
\label{subsec:comp_calc_set_software}

In this section we detail the software environment used for all calculations in this thesis. The primary quantum chemistry calculations were performed using PySCF version 2.10 \cite{Sun2020}, and SlowQuant branch Unrestricted VQE \cite{Kjellgren2026}. Numerical operations were carried out using NumPy version 1.26.4 and SciPy version 1.17, a complete list of which is provided in Table~\ref{tab:software}.

The OVOS method was implemented as a standalone Python class, with source code provided in Appendix~\ref{app:code}. All calculations were executed in a single-threaded mode to ensure reproducibility, with the environment variables \texttt{OPENBLAS\_NUM\_THREADS} and \texttt{OMP\_NUM\_THREADS} set to 1. The operating system used was Windows in Microsoft Visual Studio Code's WSL ubuntu virtual machine, as PySCF needs a Unix-like environment, and the Python distribution was standard Python version 3.11.

\subsection{Basis Sets}
\label{subsec:comp_basis_sets}

The choice of basis set determines the size of the virtual orbital space and hence the difficulty and accuracy of the OVOS calculation. This section describes the basis sets employed and provides the resulting orbital space dimensions for each molecule. See Basis Set Exchange \cite{pritchard2019a} for the source of all basis sets used in this work.

\textbf{6--31G:} A split-valence double-zeta basis set developed by Pople et. al. \cite{ditchfield1971a,dill1975a,hehre1972a}. It consists of a minimal basis for core electrons and a double-zeta basis for valence electrons, allowing for improved flexibility in describing electron correlation compared to minimal basis sets.

\textbf{cc--pVDZ:} The correlation-consistent polarized valence double-zeta basis set developed by Dunning \cite{dunning1989}. It includes polarization functions that allow for a better description of electron correlation effects, particularly important for accurate energy calculations.

\section{OVOS Calculation Settings}
\label{sec:comp_calc_set_ovos}

Running OVOS concerns two main steps: the \code{OVOS} object and the \code{OVOS.run()} method. The \code{OVOS} object is initialized with arguments that specify the molecule, the SCF object, the Fock matrix in the AO basis, the number of active virtual spin-orbitals to optimize, the initial MO coefficients from SCF, the type of initial orbitals (RHF or UHF), verbosity level, maximum number of iterations, energy and gradient convergence thresholds, and the number of iterations to keep track of for consistent convergence checks. The initialization is shown in Code~\ref{lst:ovos_init}.

\begin{lstlisting}[style=python, caption={OVOS Object}, label=lst:ovos_init]
ovos = OVOS(
    mol=mol,
    scf="scf",          
    Fao="Fock matrix in AO basis", 
    num_opt_virtual_orbs="number of active virtual spin-orbitals to optimize",  
    mo_coeff="initial MO coefficients from SCF",   
    init_orbs="RHF",         
    verbose="verbosity level (0, 1)",
    max_iter="maximum number of iterations",
    conv_energy="energy convergence threshold (e.g., 1e-8)",
    conv_grad="gradient convergence threshold (e.g., 1e-4)",
    keep_track_max="maximum number of iterations to keep track of"
)
\end{lstlisting}

The \code{OVOS.run()} method is then called to execute the orbital optimisation, as shown in Code~\ref{lst:run_init}. This method takes the initial MO coefficients and an optional spin-specific Fock matrix as arguments.

\begin{lstlisting}[style=python, caption={OVOS.run()}, label=lst:run_init]
ovos.run("initial MO coefficients from SCF", fock_spin="optional Fock matrix for spin-specific calculations")
\end{lstlisting}

For initialisation strategies see Section~\ref{sec:method_initialisation_strategies}. 

\section{VQE Calculation Settings}
\label{sec:comp_calc_set_vqe}

All VQE calculations were performed using the SlowQuant branch for unrestricted VQE \cite{Kjellgren2026}, coded up by Pernille Volsgaard Christensen Ph.D. student at Sauer Group UCPH. The VQE wave function is defined as an unrestricted wave function with a specific ansatz, here we use tiled unitary product states (tUPS) with 1 layer, and no active kappa parameters. These settings were chosen to ensure a manageable computational cost while still providing a meaningful comparison between different orbital optimisation strategies. 1 layer means that the ansatz consists of a single layer of unitary operations, which is a common choice for initial VQE studies. The decision to exclude active kappa parameters was made to simplify the wave function and focus on the effects of orbital optimisation. We change the number of electrons, the active space, the MO coefficients, and the integrals for each molecule/basis set combination, but keep the ansatz and hyperparameters fixed across all calculations. The specific implementation of the wave function is shown in Code~\ref{lst:vqe_wf}.

\begin{lstlisting}[style=python, caption={VQE Wave Function}, label=lst:vqe_wf]
UnrestrictedWaveFunctionUPS(
        num_electrons,
        active_space,
        mo_coeff_list,
        h_core_array,
        g_eri_array,
        "utups",
        {"n_layers": 1},
        include_active_kappa=False,
    )
\end{lstlisting}

We then run the optimisation using the BFGS algorithm, with orbital optimisation either enabled or disabled, and the same energy convergence threshold as OVOS (10\textsuperscript{-8} Hartree). The specific implementation of the VQE run is shown in Code~\ref{lst:run_vqe}.

\begin{lstlisting}[style=python, caption={Running VQE}, label=lst:run_vqe]
stats_ovos_opt = run_ucc_and_get_stats(WF_ovos, "BFGS", oo, atol)

def run_ucc_and_get_stats(wf, str_, oo, atol):
    ...
    wf.run_wf_optimization_1step(str_, orbital_optimization=oo, tol=atol, maxiter=5000)
    ...
\end{lstlisting}
